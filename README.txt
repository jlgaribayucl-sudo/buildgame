AR KAPALIGIRAN QUEST — V6
GitHub Pages / Netlify Publishing Package

FILES
- index.html — the complete web game
- AR_Kapaligiran_Quest_QR_Cards.pdf — printable QR cards (if included)

IMPORTANT CAMERA REQUIREMENT
The game uses the phone camera to scan QR codes. Camera access requires a secure HTTPS website.
Do NOT open index.html directly from a phone's Files/Downloads app.

GITHUB PAGES
1. Create a new GitHub repository (for example: ar-kapaligiran-quest).
2. Upload index.html and the QR PDF.
3. Go to Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and the / (root) folder, then Save.
6. Wait for deployment and open the generated https://...github.io/... address.
7. On the phone, open that HTTPS link in Chrome/Safari.
8. Allow camera permission when prompted.

NETLIFY
1. Go to Netlify and create/sign in to an account.
2. Use Add new site / Deploy manually (wording may vary).
3. Upload the folder contents, or drag the project folder into the deployment area.
4. Open the generated HTTPS site URL on the phone.
5. Allow camera permission.

TROUBLESHOOTING
- If the browser asks for camera permission, choose Allow.
- If permission was previously denied, open the browser/site permissions and allow Camera.
- Use the rear camera when prompted.
- Make sure the QR card is well lit and fills a reasonable part of the scanner box.
- The six QR values are: RIVER, CITY, FOREST, MARINE, FARM, DESERT.
- For classroom use, print the QR cards at good contrast and avoid glossy glare.

This is a static site. No server-side database is required.
